DM2000 Fader Calibration Capture - 2026-06-15
=============================================

METHODOLOGY
-----------
1. DM2000 built-in fader calibration utility run first (UTILITY menu) to align
   printed scale marks with internal motor positions.
2. DM2000 Editor used to set fader 1 to each exact dB value.
3. Channel turned off then on in editor ("confirm" sequence) to produce a
   B0 40 00 / B0 40 7F marker pair in the MIDI-OX log.
4. The last fader CC pair (B0 01 MSB + B0 21 LSB) immediately before each
   B0 40 00 is the calibrated wire value for that dB mark.
5. Wire value reconstruction: (MSB << 7) | LSB, 14-bit range 0-16383.
6. Capture port: USB port 7 (Yamaha native), fader 1, MIDI channel 1.
